# Приёмка системы тестирования

## Запуск

Используйте `pnpm run test:unit`, `pnpm run test:unit:cov`, `pnpm run test:integration` и `pnpm run test:e2e`. Unit отдельно запущен в окружении с отключённой сетью и без Docker socket. Тесты TCP и HTTP-контрактов входят в integration. Их локальные серверы используют порты, выделенные ОС. MongoDB для всех проверок хранения запускается через Testcontainers.

Все 123 исходных файла в `apps/` и `libs/` сопоставлены с отчётом или [инфраструктурным исключением](unit-coverage-infrastructure.md). В unit-отчёте 70 файлов с исполняемой логикой и 11 декларативных файлов. Для исполняемого кода все четыре метрики равны 100%.

## Скорость unit-набора

В таблице длительность из отчёта Vitest. Исторические замеры сделаны локально в ходе переноса и включают разные версии набора. Этап Orders и Products добавил основную часть тестов с pg-mem и платёжным адаптером. Ориентир полного запуска после установки зависимостей составляет 30 секунд.

| Этап | Без покрытия | С покрытием |
| --- | --- | --- |
| Первый сценарий Orders | 0,41 с | 0,42 с |
| Orders и Products | 4,85 с | 2,55 с |
| После Cart, Auth и Users | — | 4,22 с |
| Полный набор, чистый checkout | 2,76 с | 3,50 с |

Последняя пара прогонов выполнена последовательно в одном checkout после установки. По времени всей команды pnpm получилось 3,07 с без покрытия и 3,81 с с покрытием. Разница составила 0,74 с. Разные условия исторических замеров не позволяют вычесть из них стоимость покрытия.

## Обязательные проверки

В GitHub защита `master` требует статусы Unit tests, Integration tests, E2E tests, Lint и Docker build. Публикация контейнера зависит от успеха всех пяти заданий. Репозиторий также требует одобрение ревью и допускает обход защиты администраторами по действующим настройкам GitHub.

При падении Unit сохраняется вывод команды. Для Integration сохраняются вывод Vitest и логи контейнеров. Для E2E сохраняются вывод запуска, состояние контейнеров и логи сервисов до удаления Compose-проекта. Политика хранения артефактов составляет семь дней.
